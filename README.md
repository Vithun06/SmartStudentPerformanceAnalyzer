# 📊 Smart Student Performance Analyzer

A Java-based application designed to process, analyze, and evaluate student academic data to automatically generate structured performance reports.

---

### 🚀 Key Features
* **Automated Grade Calculation:** Evaluates student scores and calculates final grades seamlessly.
* **Data Processing:** Parses input data files to analyze individual student performance trends.
* **Text Report Generation:** Automatically outputs structured summary reports into `.txt` format.
* **Core Java Logic:** Built using object-oriented programming (OOP) principles for modular code structure.

---

### 🛠️ Tech Stack
* **Language:** Java (JDK 8+)
* **Concepts:** Object-Oriented Programming (OOP), File I/O, Data Processing
